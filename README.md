# Dungeon Rush Companion

Companion web para acompanhar uma partida física de Dungeon Rush.

## Executar localmente

```bash
cd /Users/kennedi.rodrigues/dungeon-rush-hud
python3 -m http.server 4173
```

Depois abra:

```text
http://localhost:4173
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Faça push deste projeto para o repositório.
3. Ative GitHub Pages no GitHub.
4. Use a branch `main` (ou `master`) e a pasta raiz.

Este app é estático, então não precisa de build.
